\[SpringJPA 2주차 스터디]



**JPA의 특징**

* 어노태이션을 이용한 매핑 설정
* String, int, LocalDate 등 기본적인 타입에 대한 매핑 지원
* 커스텀 타입 변환기 지원
* 밸류 타입 매핑 지원
* 클래스 간 연관 지원: 1-1, 1-N, N-1, N-M
* 상속에 대한 매핑 지원



**코드구조 \& 영속 컨텍스트**

영속성 단위로 JPA 초기화 → EntityManager로 DB 작업 → 사용 후 자원 반환\*\*



* persistence.xml 에 정의한 영속성 단위 이름으로 JPA를 초기화한다.
* jpabegin 이라는 이름을 기준으로 EntityManagerFactory를 생성함.
* JPA에서 DB 작업은 EntityManager를 통해 수행한다.

&#x20;   - 엔티티 저장은 entityManager.persist()처럼 처리함.

* 사용이 끝나면 자원을 닫아야 한다.

&#x20;   - EntityManager와 EntityManagerFactory를 close()해서 자원을 반환함.



**엔티티 단위 CRUD 처리**

* EntityManager를 사용해서 엔티티 단위로 CRUD 처리
* 데이터 변경 작업은 트랜잭션 범위 안에서 실행

&#x20;   - persist() : 저장

&#x20;   - 엔티티 값 변경 : 수정

&#x20;   - remove() : 삭제

* 기본 애노테이션

&#x20;   - @Entity : 엔티티 클래스에 설정, 필수

&#x20;   - @Table : 매핑할 테이블 지정

&#x20;   - @Id : 식별자 속성에 설정, 필수

&#x20;   - @Column : 매핑할 칼럼명 지정

&#x20;       - 지정하지 않으면 필드명/프로퍼티명 사용

&#x20;   - @Enumerated : enum 타입을 매핑할 때 사용



**엔티티 식별자 생성 방식**

* 직접 생성 방식

&#x20;   - @Id가 설정된 대상에 식별자 값을 직접 지정

&#x20;   - 사용자가 입력한 값이나 규칙에 따라 생성한 값을 사용

&#x20;   - 저장하기 전에 식별자를 먼저 할당

&#x20;   - 보통 객체 생성 시점에 식별자 값을 전달해 설정함

&#x20;   

* 식별 칼럼 방식

&#x20;   - DB의 식별 칼럼에 매핑

&#x20;       - 예: MySQL의 AUTO\_INCREMENT

&#x20;   - DB가 식별자를 생성하므로 객체 생성 시 식별자 값을 직접 설정하지 않음

&#x20;   - @GeneratedValue(strategy = GenerationType.IDENTITY) 설정

&#x20;   

* 시퀀스 사용 방식

&#x20;   - 저장 시점에 시퀀스를 사용해서 식별자 생성

* 테이블 저장 방식

&#x20;   - 저장 시점에 별도의 테이블을 사용해서 식별자 생성



**@Embeddedable**



* 엔티티가 아닌 타입을 하나 이상의 필드와 매핑할 때 사용
* 엔티티의 한 속성으로 @Embeddable이 적용된 타입을 사용할 수 있음
* 여러 개의 관련 속성을 하나의 타입으로 묶어 모델을 더 명확하게 표현할 수 있음
* 개별 속성을 따로 보는 것보다 의미 있는 객체 단위로 이해하기 쉬워짐



**@SecondaryTable**



* 하나의 엔티티를 여러 테이블에 매핑할 때 사용
* 다른 테이블에 저장된 데이터도 하나의 엔티티에서 함께 다룰 수 있음
* 다른 테이블에 저장된 값이 개념적으로 하나의 값 객체라면 @Embeddable과 함께 사용할 수 있음
* 특히 1:1 형태로 두 테이블의 정보를 하나의 엔티티에 매핑할 때 자주 사용됨
