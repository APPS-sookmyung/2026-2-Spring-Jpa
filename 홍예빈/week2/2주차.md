# JPA 기초 01. 일단 해보기

### JPA

자바 객체와 관계형 DB 간의 매핑 처리를 위한 API

보통 JPA 단독보다 스프링과 함께 사용

### JPA 특징

1. 애노테이션을 이용한 매핑 설정
2. String, Int, LocalDate 등 기본적인 타입에 대한 매핑 지원
3. 커스텀 타입 변환기 지원
4. 밸류 타입 매핑 지원
5. 클래스 간 연관 지원
6. 상속에 대한 매핑 지원

# JPA 기초 03. 엔티티 CRUD 처리

### 엔티티 단위 CRUD 처리

EntityManager가 제공하는 메서드 이용

- persist() : 저장
- find() : 조회
    - 조회 시 주의점 : 엔티티 타입과 ID 타입이 일치해야 함 but 그렇지 않다면 익셉션 발생
- remove() : 삭제
    - 삭제 시 주의점 : 삭제 대상이 존재하지 않으면 익셉션 발생
- merge()

# JPA 기초 04. 엔티티 매핑 설정

### 기본 애노테이션

1. @Entity : 엔티티 클래스에 설정, 필수
2. @Table : 매핑할 테이블 지정
3. @Id : 식별자 속성에 설정, 필수
4. @Column : 매핑할 칼럼명 지정
5. @Enumerated : enum 타입 매핑할 때 설정

# JPA 기초 05. 엔티티 식별자 생성 방식

### 식별자 생성 방식

1. 직접 할당
2. 식별 칼럼 방식 : 저장 시점에 INSERT 쿼리 실행
3. 시퀀스 사용 방식 : 저장 시점에 시퀀스 사용해서 식별자 생성
4. 테이블 사용 방식 : 저장 시점에 테이블 사용해서 식별자 생성

# JPA 기초 06. Embeddable

### @Embeddable

엔티티가 아닌 타입을 한 개 이상의 필드와 매핑할 때 사용 ex. Address, Money

엔티티의 한 속성으로 @Embeddable 적용 타입 사용

같은 @Embeddable 타입 필드가 두 개면 → @AttributeOverride으로 재정의

# JPA 기초 07. Embeddable 다른 테이블에 매핑하기

### 다른 테이블에 값을 저장할 때

1. @SecondaryTable + 테이블명
2. @SecondaryTable + @AttributeOverride

### @SecondaryTable

다른 테이블에 저장된 데이터를 @Embeddable로 매핑 가능

다른 테이블에 저장된 데이터가 개념적으로 값일 때 사용
