# 3. 애플리케이션 구현 준비

도메인 설계를 완료했으므로 이제 실제 애플리케이션 기능을 구현하기 위한 구조를 준비

## 3-1. 구현 요구사항

### 회원 기능
- 회원 등록
- 회원 조회

### 상품 기능
- 상품 등록
- 상품 수정
- 상품 조회

### 주문 기능
- 상품 주문
- 주문 내역 조회
- 주문 취소

예제를 단순하게 만들기 위해 다음 기능은 구현하지 않는다.

- 로그인 및 권한 관리 X
- 파라미터 검증 및 예외 처리 X
- 상품은 **도서(Book)** 만 사용
- 카테고리 기능 X
- 배송 정보 기능 X

---

## 3-2. 애플리케이션 아키텍처

애플리케이션은 **계층형 구조**로 개발한다.



### Controller / Web
웹 요청을 받고 사용자에게 결과를 반환하는 **웹 계층**

### Service
실제 **비즈니스 로직**을 처리하고 트랜잭션 관리

### Repository
JPA를 직접 사용하는 계층

`EntityManager`를 사용하여 데이터의 저장, 조회 등을 처리한다.

### Domain
`Member`, `Order`, `Item`과 같은 **엔티티가 모여 있는 계층**

Domain은 다른 계층에서 공통으로 사용된다.

---

## 3-3. 패키지 구조

```text
jpabook.jpashop
 ├─ domain
 ├─ exception
 ├─ repository
 ├─ service
 └─ web
```

- `domain` : 엔티티
- `exception` : 예외 처리
- `repository` : DB 접근
- `service` : 비즈니스 로직
- `web` : Controller 및 웹 기능

---

## 3-4. 개발 순서

먼저 **서비스와 리포지토리 계층을 구현하고 테스트를 통해 기능이 정상적으로 동작하는지 확인한 뒤**, 마지막에 웹 화면과 연결한다.
